# goaround-weather-classification

Воспроизводимое исследование прогнозирования метки ухода на второй круг (GoA) по признакам C40: сравнение Logistic Regression и CatBoost без погоды и с METAR. Проект выделен из Approach Risk ver. 1.0 с соответствующей историей разработки.

## Исследовательский вопрос

Улучшает ли добавление погодных признаков ранжирование редкого события? Дает ли градиентный бустинг существенный дополнительный результат относительно линейного классификатора? Оценка выполнена на одинаковых событиях внутри сравниваемых пар, с временным разбиением и сохраненными протоколами.

## Методика

- Бинарная классификация с учителем: Logistic Regression L2, C=1; CatBoost 1.2.10 с Logloss.
- Train 2019–2021: **4 165 060 событий / 11 626 GoA**.
- Validation 2022: **1 619 848 / 4 984**.
- Test – наблюдаемая часть 2023 года: **546 577 / 1 739**; доля GoA **0,3182%**.
- Преобразования оцениваются на train; конфигурации и пороги выбираются на validation.
- CatBoost: десять кандидатов по 500 деревьев, CPU. Выбран baseline depth=8, learning_rate=0.1; weather depth=4, learning_rate=0.1.
- Сравниваются AP, ROC-AUC, Brier, precision–recall, калибровка и перенос порогов. Для погодного эффекта выполнен парный bootstrap по UTC-дням.

## Результаты на одинаковом test

| Модель | Признаки | AP | ROC-AUC | Brier |
|---|---|---:|---:|---:|
| Logistic | Без погоды | 0,003989 | 0,5682 | 0,003171 |
| Logistic | С погодой | 0,006679 | 0,6084 | 0,003168 |
| CatBoost | Без погоды | 0,004361 | 0,5711 | 0,003172 |
| CatBoost | С погодой | **0,006812** | **0,6237** | 0,003168 |

Погода улучшила выбранные пары обоих семейств. Для CatBoost прирост AP составил **0,002451**; дневной парный bootstrap-интервал 95% **[0,001304; 0,003992]**, условный на выбранных моделях. Погодный CatBoost прибавил около **1,99% AP** относительно погодной Logistic. Значимость различия семейств отдельно не проверялась; Brier при переходе к погодному CatBoost немного ухудшился, что скрыто округлением таблицы.

При пороге, выбранном для validation FPR ≤ 1%, погодный CatBoost на test обнаружил **6,73% GoA** при **FPR 1,31%**, precision **1,61%**. Рост ранжирования пока не означает практической пригодности системы предупреждений.

У Logistic дополнительно проверена чувствительность фиксированной модели к задержкам METAR 0/15/30 минут и исключению COR. Для новой пары CatBoost такие проверки не выполнены. Важности признаков не являются доказательством причинного эффекта.

## Структура

| Путь | Содержание |

Пути исследований сохранены для воспроизведения. Подготовка выборки и аудит METAR оформлены отдельно в goaround-metar. Здесь задача – сравнение классификаторов, а не новое декодирование погоды.

## Воспроизведение

Python ≥ 3.11. Из корня:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m pip install -e ".[boosting]"
.\.venv\Scripts\python.exe scripts/verify_shared_architecture.py
.\.venv\Scripts\python.exe research/boosting-weather-comparison/scripts/verify_training.py
```

Проверки используют сохраненные данные и модели, без нового обучения. Для публичного клона они должны быть получены отдельно. [Требования к данным](DATA_REQUIREMENTS.md). Для просмотра выводов достаточно сохраненных ноутбуков, таблиц и графиков.

## Ограничения

Метки исходного детектора не являются независимо подтвержденными эксплуатационными уходами. Историческое фактическое время получения погоды неизвестно. Test ранее просматривался в исследованиях: это исследовательское сравнение, независимый подтверждающий период отсутствует. Метрики действуют внутри покрытия C40; не распространяются автоматически на все заходы.

Новые настройки не следует выбирать по этому test. Следующее исследование требует отдельного протокола и независимого периода. Сырые данные, модели, статьи и Checkpoint исключены из Git.
